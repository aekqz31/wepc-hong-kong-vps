## 绕路线路、5Mbps 限速、禁 Shadowsocks：下单前必须知道的四条

**线路是绕路，不是三网直连优化。** 官网原话是“三网绕路，可用性高，联通优秀”。这几个字值得读两遍。它的意思是这条线追求的是可用性和联通方向的质量，不是电信 CN2、移动 CMI 那种针对性优化。电信和移动用户直连体验可能一般，用香港或日本节点中转是常见做法。冲着“香港直连低延迟建站”来的读者，这条线不是为你准备的。

**超额流量限速 5Mbps，不停机。** 2TB 或 8TB 用完之后，带宽降到 5Mbps，服务器继续跑，不会断服也不会额外账单。5Mbps 大约是每秒 600 多 KB，够跑一个文字博客或低频 API，跑视频和下载就不行了。这个设计对怕超流量被停机的人友好，对大流量业务则是硬上限。

**禁止使用 Shadowsocks 协议。** 这是官方明确写出的使用限制，违反可能导致服务被停。买之前确认你的用途在允许范围内。
